# 🌐 Portafolio Web Personal – Diego Ruiz

Este proyecto consiste en el desarrollo de un portafolio web personal utilizando únicamente HTML y CSS básico, siguiendo buenas prácticas de estructura semántica, accesibilidad y diseño responsivo.

## 📌 Descripción

El portafolio presenta información profesional, habilidades técnicas, proyectos desarrollados y datos de contacto, organizados de forma clara y estructurada, replicando la lógica de un sitio web profesional.

## 🧠 Características principales

- Uso de HTML semántico (`header`, `nav`, `main`, `section`, `article`, `footer`)
- Diseño con CSS básico y limpio
- Navegación entre secciones
- Enlaces internos y externos
- Integración de contacto:
  - Correo (mailto)
  - Teléfono (tel)
  - GitHub
  - Instagram
- Accesibilidad:
  - Atributo `lang="es"`
  - Uso de `alt` en imágenes
  - Navegación accesible con lector de pantalla
- Diseño responsive para dispositivos móviles
- Botón para descarga de CV
